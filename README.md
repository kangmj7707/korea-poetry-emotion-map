# 한국 시 감정 지도

한국 근현대 대표 시 15편의 정서를 **감정 사전**과 **문학적 해석**으로 함께 분석하고, 사용자가 직접 입력한 시의 감정까지 실시간으로 분석하는 웹앱입니다.
시를 고르면 지배 정서 비율, 감상과 해석, 독자 감정 상태 매칭, 비슷한 감성의 시 추천, 감정 프로필 레이더 차트(확대 모달 지원)를 한눈에 볼 수 있습니다.

**바로 보기:** [https://kangmj7707.github.io/korea-poetry-emotion-map/](https://kangmj7707.github.io/korea-poetry-emotion-map/)

설치나 회원가입 없이 웹 브라우저만 있으면 됩니다. 핵심 파일은 `index.html` 하나입니다.

| 메뉴 | 내용 |
|---|---|

## 분석 방법

1. **9대 정서:** 비애·슬픔, 그리움·향수, 의지·저항, 성찰·고뇌, 사랑·연모, 고독·적막, 희망·동경, 원망·분노, 평온·달관
2. **감정 사전 점수:** 시 본문에서 정서별 등록 시어(`LEXICON`)의 등장 횟수와 강도 가중치(`1~3점`)를 합산해 백분율로 환산합니다.
3. **해석 기반 프로필:** 반어나 역설, 문맥적 의미를 반영해 작품마다 정서 비율(`interpScores`)을 설정한 값입니다.
4. **최종 점수:** `해석 기반 프로필 × (1 - w) + 감정 사전 점수 × w`. 대시보드 상단 슬라이더로 `w`를 0~100%까지 조절할 수 있습니다. (직접 입력한 시는 사전 점수만으로 분석)
5. **독자 감정 상태 매칭 및 추천:** 최종 점수 1위 정서를 기준으로 독자 감정 상태 매칭 문구를 출력하며, 감정 벡터 간 코사인 유사도를 계산해 유사도가 높은 순으로 3편을 추천합니다.

## 생성형 AI 활용 내역

본 프로젝트는 개발 및 콘텐츠 구성 과정에서 생성형 AI(**Google Gemini**)를 보조 도구로 활용하였으며, 모든 산출물은 직접 실행·검증 후 수정하여 반영했습니다.

| 활용 영역 | 사용 도구 | 구체적 활용 내용 |
|---|---|---|
| 웹앱 구조 설계 및 기능 구현 | Gemini | 단일 `index.html` 기반 대시보드 레이아웃 설계, **독자 감정 상태 매칭 카드 로직**, Chart.js 레이더 차트 및 확대 모달, 코사인 유사도 추천 및 사용자 입력 시 실시간 분석(`analyzeCustomPoem`) JavaScript 구현 |
| 문학 데이터·감정 사전·매칭 문구 보완 | Gemini | 수록 시 15편의 주제·감상 해설 초안 정리, 9대 정서별 감정 사전(`LEXICON`) 시어 확장, **정서별 독자 감정 상태 매칭(`match`) 큐레이션 문구** 및 해석 기반 정서 비율(`interpScores`) 수치 검토 |
| 배포 및 문서화 | Gemini | GitHub Pages 배포 설정 안내(`.nojekyll`) 및 프로젝트 `README.md` 문서 구조화 |
