# 한국 시 감정 지도

한국 근현대 대표 시 15편의 정서를 **감정 사전**과 **문학적 해석**으로 함께 분석하고, 사용자가 직접 입력한 시의 감정까지 실시간으로 분석하는 웹앱입니다.
시를 고르면 지배 정서 비율, 감상과 해석, 독자 상태 매칭, 비슷한 감성의 시 추천, 감정 프로필 레이더 차트(팝업 확대 지원)를 볼 수 있습니다.

**바로 보기:** https://kangmj7707.github.io/korea-poetry-emotion-map/

설치나 회원가입 없이 웹 브라우저만 있으면 됩니다. 핵심 파일은 `index.html` 하나입니다.

## 기능

| 메뉴 | 내용 |
|---|---|
| 수록 작품 (15편) | 왼쪽 목록에서 시를 선택해 원문과 분석 결과를 즉시 확인 |
| 시 본문 | 감정 사전과 일치한 시어 하이라이트 및 마우스 오버 시 감정 범주·가중치(1~3점) 툴팁 표시 |
| 분석 가중치 슬라이더 | 0~100% 범위에서 1% 단위로 해석 중심과 사전 중심의 반영 비율을 조절(기본값 50%) |
| 지배 정서 비율 | 상위 감정의 비율을 막대 차트로 시각화 |
| 감상과 해석 | 작품의 주제와 감상·해석 안내 |
| 독자 상태 매칭 | 현재 시의 지배 정서에 어울리는 독자 상태 추천 문구 제공 |
| 비슷한 감성의 시 추천 | 코사인 유사도 기반으로 감정 구성이 비슷한 시 상위 3편 추천 |
| 감정 프로필 | 9대 정서 레이더 차트 제공 및 클릭/터치 시 화면 중앙 확대 모달 지원 |
| 내 시 분석하기 | 제목과 시 본문을 직접 입력하면 감정 사전(`w = 100%`)으로 분석해 근거 시어와 가장 비슷한 수록 시를 추천(미감지 시 안내 배너 출력) |

## 분석 방법

1. **9대 정서:** 비애·슬픔, 그리움·향수, 의지·저항, 성찰·고뇌, 사랑·연모, 고독·적막, 희망·동경, 원망·분노, 평온·달관
2. **감정 사전 점수:** 시 본문에서 정서별 등록 시어(`LEXICON`)의 등장 횟수와 강도 가중치(`1~3점`)를 합산해 백분율로 환산합니다.
3. **해석 기반 프로필:** 반어나 역설, 문맥적 의미를 반영해 작품마다 정서 비율(`interpScores`)을 설정한 값입니다.
4. **최종 점수:** `해석 기반 프로필 × (1 - w) + 감정 사전 점수 × w`. 대시보드 상단 슬라이더로 `w`를 0~100%까지 조절할 수 있습니다. (직접 입력한 시는 사전 점수만으로 분석)
5. **추천:** 감정 벡터 간 코사인 유사도를 계산해 유사도가 높은 순으로 추천합니다.
